EINMALIGE EINRICHTUNG (nur beim allerersten Mal nötig)

1. loader.lua und client_loader.lua (aus MTASA-crypto\) je einmal auf
   luac.mtasa.com hochladen und kompilieren.
   → Die beiden entstehenden .luac-Dateien in MTASA-crypto\ ablegen
     (überschreibt evtl. vorhandene .luac dort).
   → Dieser Ordner MTASA-crypto\ muss immer NEBEN der .exe liegen –
     das Tool kopiert daraus automatisch in jede neue Resource.

Das war's mit dem Einmal-Kram. Ab jetzt läuft alles automatisch.

NORMALER ABLAUF (für jede Datei / jedes Script)

1. ICE-Crypt-Encrypt.exe öffnen
2. Lua-Datei(en) per Drag & Drop in den Resource-Ordner-Bereich ziehen
   → [C] = Client-Script  |  [S] = Server-Script  (automatisch erkannt)
3. "ENCRYPT" klicken

  Das Tool macht automatisch ALLES Weitere:
    • verschlüsselt die Datei(en)  → .lua.enc
    • schreibt _manifest.txt
    • erstellt/liest _key.txt
    • kopiert loader.luac, client_loader.luac, ice_config.txt
      in den Resource-Ordner (falls noch nicht vorhanden)
    • trägt loader.luac / client_loader.luac / ice_config.txt
      und den aclrequest-Block in die meta.xml ein (falls noch nicht drin)

4. Resource im MTA-Server starten:  restart <resourceName>

5. NUR BEIM ALLERERSTEN START einer neuen Resource, einmalig in der
   MTA-Server-Konsole (schwarzes Fenster):
       aclrequest allow <resourceName> function.loadstring
   → Danach: restart <resourceName>
   Das ist eine MTA-Sicherheitssperre, die kein Script automatisch
   umgehen kann – nur ein Admin darf das per Konsole freigeben.
   Einmal erledigt, bleibt es für diese Resource dauerhaft erlaubt.

Ab dann: einfach Dateien verschlüsseln und in den Ordner werfen –
alles andere passiert von selbst.

SPRACHE DES LOADERS ÄNDERN
  ice_config.txt in der Resource öffnen → LANG=DE auf EN oder TR

ONE-TIME SETUP (only needed the very first time)

1. Upload loader.lua and client_loader.lua (from MTASA-crypto\) to
   luac.mtasa.com once and compile them.
   → Save the two resulting .luac files into MTASA-crypto\
     (overwrite any existing .luac there).
   → This MTASA-crypto\ folder must always sit NEXT TO the .exe –
     the tool copies from it into every new resource automatically.

That's the only one-time step. From here on everything is automatic.

NORMAL WORKFLOW (for every file / every script)

1. Open ICE-Crypt-Encrypt.exe
2. Drag & drop Lua file(s) into the file list
   → [C] = Client script  |  [S] = Server script  (auto-detected)
3. Click "ENCRYPT"

  The tool automatically does EVERYTHING else:
    • encrypts the file(s)  → .lua.enc
    • writes _manifest.txt
    • creates/reads _key.txt
    • copies loader.luac, client_loader.luac, ice_config.txt
      into the resource folder (if not already present)
    • adds loader.luac / client_loader.luac / ice_config.txt
      and the aclrequest block to meta.xml (if not already there)

4. Start the resource on the MTA server:  restart <resourceName>

5. ONLY ON THE VERY FIRST START of a new resource, once in the
   MTA server console (black window):
       aclrequest allow <resourceName> function.loadstring
   → Then: restart <resourceName>
   This is an MTA security gate that no script can bypass
   automatically – only an admin can approve it via console.
   Once done, it stays approved for that resource permanently.

From then on: just encrypt files and drop them in the folder –
everything else happens on its own.

CHANGE LOADER LANGUAGE
  Open ice_config.txt in the resource → change LANG=EN to DE or TR

TEK SEFERLİK KURULUM (yalnızca ilk seferde gerekli)

1. loader.lua ve client_loader.lua dosyalarını (MTASA-crypto\ içinden)
   birer kez luac.mtasa.com'a yükleyip derle.
   → Ortaya çıkan iki .luac dosyasını MTASA-crypto\ içine kaydet
     (orada varsa eski .luac dosyalarının üzerine yaz).
   → Bu MTASA-crypto\ klasörü her zaman .exe'nin YANINDA durmalı –
     araç oradan her yeni resource'a otomatik olarak kopyalar.

Tek seferlik iş bu kadar. Bundan sonra her şey otomatik çalışır.

NORMAL AKIŞ (her dosya / her script için)

1. ICE-Crypt-Encrypt.exe'yi aç
2. Lua dosyalarını sürükle-bırak ile listeye ekle
   → [C] = İstemci scripti  |  [S] = Sunucu scripti  (otomatik algılanır)
3. "ENCRYPT" butonuna tıkla

  Araç geri kalan HER ŞEYİ otomatik yapar:
    • dosyaları şifreler  → .lua.enc
    • _manifest.txt yazar
    • _key.txt oluşturur/okur
    • loader.luac, client_loader.luac, ice_config.txt dosyalarını
      resource klasörüne kopyalar (henüz yoksa)
    • loader.luac / client_loader.luac / ice_config.txt ve
      aclrequest bloğunu meta.xml'e ekler (henüz yoksa)

4. Resource'u MTA sunucusunda başlat:  restart <resourceName>

5. Yeni bir resource'un YALNIZCA İLK BAŞLATILMASINDA, MTA sunucu
   konsolunda (siyah pencere) bir kez:
       aclrequest allow <resourceName> function.loadstring
   → Sonra: restart <resourceName>
   Bu, hiçbir scriptin otomatik olarak atlayamayacağı bir MTA
   güvenlik kilididir – yalnızca bir admin konsoldan onaylayabilir.
   Bir kez yapıldıktan sonra o resource için kalıcı olarak onaylı kalır.

Bundan sonra: sadece dosyaları şifrele ve klasöre bırak –
geri kalan her şey kendiliğinden olur.

LOADER DİLİNİ DEĞİŞTİR
  Resource'daki ice_config.txt'yi aç → LANG=TR değerini DE veya EN yap
